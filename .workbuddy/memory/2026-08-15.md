# 2026-08-15 工作日志

## 创建 qmt-trader skill

为项目创建了一个大模型可调用的 QMT 交易/行情 skill，位于项目级 `.workbuddy/skills/qmt-trader/`。

### skill 结构
- `SKILL.md` — 主文件，含命令速查、典型工作流、安全须知
- `scripts/qmt.py` — 统一 CLI 入口，21 个子命令（ping/account/positions/orders/trades/tick/kline/instrument/sector/trading-dates/north/longhubang/financial/download/buy/sell/cancel/snapshot/quote-subscribe）
- `references/api_reference.md` — 完整 API 参考手册（参数/返回值/常量/陷阱/方法白名单）

### 设计要点
- CLI 脚本而非让 LLM 现场写 Python —— 确定性调用，JSON 输出便于解析
- 脚本自动发现仓库 src/ 并加入 sys.path，开发模式直接可用
- 配置从环境变量或 bigqmt_signal_trader_client_config.py 读取
- 下单命令支持 --dry-run 和 --latest，安全防重复下单逻辑
- 打包验证通过：`D:\gjzqqmt\xtquant_big_convert\dist\qmt-trader.zip`

### skill-creator 注意事项
- 验证器 `quick_validate.py` 的 description 正则 `description:\s*(.+)` 只抓第一行，不支持 YAML 块标量 `>-` 语法（`>` 会被误判为尖括号），description 必须用单行字符串
